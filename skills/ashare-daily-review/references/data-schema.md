# 数据 Schema：占位符 ↔ 数据字段对照表

模板 `templates/report-template.html` 中所有 `{{TOKEN}}` 的填充规则。
本文件只定义**字段语义与计算口径**，**不绑定任何固定程序、脚本路径或内置命令**。你可以从 API、CSV、数据库结果、网页检索结果或用户直接提供的数据中取值，只要字段含义一致即可。

## 2. 指数卡片（`SH` / `SZ` / `CY` / `KC`）

| TOKEN | 字段要求 |
| --- | --- |
| `{X}_CLOSE` | 最新收盘点位或报告时点最新点位 |
| `{X}_CHG` | 当日涨跌额，带正负号 |
| `{X}_CHG_PCT` | 当日涨跌幅，带 `%` |
| `{X}_DIR` | 涨跌方向：上涨填 `up`，下跌填 `down` |
| `{X}_AMT` | 当日成交额，建议统一转成“亿元” |
| `{X}_CHG_5D` | 近 5 个交易日涨跌幅 |
| `{X}_CHG_20D` | 近 20 个交易日涨跌幅 |
| `{X}_AMT_CHG` | 与上一交易日相比的成交额变化百分比 |

> 计算建议：`{X}_AMT_CHG = (今日成交额 / 昨日成交额 - 1) × 100%`

## 3. 市场情绪

| TOKEN | 字段要求 |
| --- | --- |
| `SENTI_ON_HOT` / `SENTI_ON_BULL` / `SENTI_ON_BEAR` / `SENTI_ON_PANIC` | 四选一命中的项填 ` on`，其余留空 |
| `SENTI_RESULT` | 情绪档位结论：过热 / 偏多 / 偏空 / 恐慌 |
| `SENTI_SUBTITLE` | 一句话总结 |
| `SENTI_ANALYSIS` | 3~4 条 `<li>`，需解释判断依据以及“为什么不是相邻档” |

### 情绪判断建议口径
- **过热**：上涨家数占比很高，涨停数明显增多，且成交额放大，风险偏好极强。
- **偏多**：上涨家数占优，量能健康，主流指数多数收红，但未达到过热。
- **偏空**：下跌家数偏多或量能不足，情绪承压，但尚未出现明显恐慌踩踏。
- **恐慌**：跌停数量明显增多、放量长阴、破位个股多，风险偏好快速收缩。

可用的基础输入包括但不限于：上涨/下跌家数、涨停/跌停数量、两市成交额及变动、市场宽度、热点扩散度、市场画像评分。

## 4. 成交量

| TOKEN | 字段要求 |
| --- | --- |
| `TOTAL_AMT` | 两市总成交额 |
| `TOTAL_AMT_DIFF` | 相比上一交易日的成交额变化值 |
| `TOTAL_AMT_Y` | 上一交易日成交额 |
| `TOTAL_AMT_DIFF_PCT` | 相比上一交易日的成交额变化百分比 |
| `VOL_DIR` | 放量填 `up`，缩量填 `down` |
| `VOL_BAR_T` | 今日成交额柱宽占比（与昨日合计为 100） |
| `VOL_BAR_Y` | 昨日成交额柱宽占比 |
| `VOL_COMMENT` | 一句话解释量价关系 |

## 5. 技术形态（`T_SH` / `T_SZ` / `T_CY` / `T_KC`）

| TOKEN | 字段要求 |
| --- | --- |
| `{X}_ANALYSIS` | 4~5 条 `<li>`，必须按当日显著性排序 |
| `{X}_SUPPORT` | 支撑位描述：可综合今日低点、短中期均线、BOLL 下轨、周内低点 |
| `{X}_RESIST` | 压力位描述：可综合今日高点、短中期均线、BOLL 上轨、周内高点 |

### 推荐原始输入
- 最近约 40 个交易日日线 K 线
- MA5 / MA10 / MA20 / MA60
- MACD（DIF / DEA / BAR）
- KDJ（K / D / J）
- RSI（6 / 12 / 24）
- BOLL（上轨 / 中轨 / 下轨）
- 最近约 3 个交易日分钟级数据，用于 5 分钟 MACD 背离分析

## 6. 板块涨跌（`G1-G3` 涨幅榜，`L1-L3` 跌幅榜）

| TOKEN | 字段要求 |
| --- | --- |
| `SECTOR_CALIBER` | 板块统计口径，例如“申万一级行业” |
| `{G/L}#_NAME` | 板块名称 |
| `{G/L}#_PX` | 板块最新点位 |
| `{G/L}#_CHG` | 当日涨跌幅 |
| `{G/L}#_5D` | 近 5 个交易日涨跌幅 |
| `{G/L}#_20D` | 近 20 个交易日涨跌幅 |
| `{G/L}#_DIR` | 涨跌方向：`up` / `down` |
| `GAINER_ANALYSIS` | 涨幅榜逐条分析，每条一个 `<li>` |
| `LOSER_ANALYSIS` | 跌幅榜逐条分析，每条一个 `<li>` |

### 口径要求
- 涨幅榜与跌幅榜必须使用**同一行业分类口径**。
- 若数据源只提供涨幅榜，没有跌幅榜，必须从全量板块列表自行排序补齐。
- 若分析中引用龙头股、资金流或新闻，需明确这些信息是附加解释，不能改变榜单排序口径。

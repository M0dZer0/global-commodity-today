# A股每日复盘报告

## When to use
用户要求生成 A 股每日/当日复盘报告、收盘总结、大盘日报，尤其是要求“市场概览 + 技术形态 + 板块涨跌 + 关注板块 + 外围市场 + 总结策略”结构，并输出 HTML 和/或 PNG 长图时使用。

## 核心原则
- **数据源不绑定特定内置程序**：可使用任意等价数据源，只要字段完整、口径一致、可复核即可。
- **优先使用结构化输入**：若调用方已经提供 JSON、CSV、数据库结果、接口返回或本地缓存，直接复用，不要求再通过某个固定脚本取数。
- **允许多源拼接**：指数行情、技术指标、板块榜单、新闻事件、外围市场可以来自不同数据源，但同一模块内必须统一统计口径。
- **禁止暴露本机信息**：说明、示例、命令、交付物中都不要出现个人电脑用户名、绝对路径、桌面目录、应用安装路径等信息。

## 产物与依赖
- 模板：`templates/report-template.html`（所有 `{{TOKEN}}` 为占位符）
- 占位符映射：`references/data-schema.md`
- 5分钟 MACD 辅助脚本：`scripts/min5_macd.py`

## 可接受的数据输入
以下输入方式都可以驱动本 skill：

- **行情接口**：任意能返回指数/板块/商品/海外市场行情的 HTTP API、SDK 或命令行工具
- **本地数据文件**：JSON、CSV、Markdown 表格、缓存快照
- **数据库/查询结果**：只要字段能映射到模板占位符即可
- **网页检索结果**：适用于日韩指数涨跌幅、当日热点、AI/半导体相关新闻等补充信息

若存在多个来源，按以下优先级选择：
1. 当轮上下文中用户已提供的数据
2. 可复现的结构化接口或本地缓存
3. 网页检索或公开页面补齐

## 推荐工作流
1. **确认交易日与报告日期**：生成 `REPORT_DATE`、`REPORT_WEEKDAY`、`NEXT_DATE`，并确认是否为交易日复盘。
2. **采集四大指数数据**：上证指数 `sh000001`、深证成指 `sz399001`、创业板指 `sz399006`、科创50 `sh000688`。至少准备：最新点位、涨跌额、涨跌幅、成交额、近 5/20 日表现、最近 40 个交易日 K 线、近 3 日分钟级数据。
3. **采集市场宽度与情绪素材**：至少包括上涨家数、下跌家数、涨停/跌停、大盘成交额及较上一交易日变动；若有市场画像评分也可纳入，但要注明是否滞后。
4. **采集板块榜单**：给出统一口径下的涨幅前三与跌幅前三。若某来源只有涨幅榜、没有跌幅榜，就从完整板块列表中自行计算排序。
5. **采集关注板块**：默认半导体、通信、有色金属；若用户指定其他板块，则以用户指定为准。需要最新点位、当日/5日/20日表现，以及 MACD/RSI/BOLL/KDJ 等技术面材料。
6. **采集外围市场与新闻**：纳斯达克、韩国综合、日经225；若个别来源只提供价格、不提供涨跌幅，可改用公开检索补齐。同步收集与 AI、半导体、风险偏好相关的新闻。
7. **执行 5 分钟级别背离分析**：使用 `scripts/min5_macd.py` 对上证指数、创业板指等分钟级数据做 5 分钟聚合与 MACD 背离/金死叉检测。
8. **撰写分析结论**：情绪判断必须综合市场宽度、量能、指数结构、热点扩散度，不能只看指数涨跌；技术分析必须按当日显著性排序，不要机械罗列指标。
9. **填充模板**：复制 `templates/report-template.html` 为交付文件，替换全部 `{{TOKEN}}`；上涨使用 `up`，下跌使用 `down`；情绪档位对应芯片加 ` on`。
10. **导出长图（可选）**：若用户要求 PNG 长图，可使用任意支持无头截图的浏览器或渲染器分段导出，不要求依赖某个固定应用路径。

## 长图导出建议
- 模板按移动端阅读设计，整页可能非常长。
- 无头浏览器通常存在单张截图高度上限，整页导出容易出现底部空白或截断。
- 建议按 `<section>` 边界拆成 3~4 段分别导出，再交付多张 PNG。
- 若采用脚本化截图，请将浏览器可执行文件配置为**环境变量、PATH 命令或调用方自定义参数**，不要写死本机安装路径。

## 分析要求
- **情绪分档**：在“过热 / 偏多 / 偏空 / 恐慌”中四选一，并解释为什么不是相邻档。
- **技术分析排序**：先写最重要的信号，例如放量突破、缩量回踩、顶/底背离、BOLL 轨道突破、关键均线失守，再写常规指标状态。
- **板块分析**：同一榜单中的涨跌幅、近 5 日、近 20 日数据必须来自同一口径。
- **外围联动**：优先解释 AI、半导体、风险偏好、商品价格对 A 股情绪的传导。
- **策略表达**：给出条件化判断与应对方案，不做绝对化承诺。

## Pitfalls
- 某些数据源只有涨幅榜没有跌幅榜，需自行补算跌幅榜。
- 某些海外指数只返回价格，不返回涨跌幅，需另行补齐。
- 不同供应商的行业分类可能是申万一级、申万二级或自定义主题，报告中必须注明口径，不要混写。
- 分钟级数据聚合时要确认时间粒度、时区、停牌缺口与首根 K 线定义一致。
- 长图导出前必须检查每张 PNG 是否完整显示 footer、无明显空白、无内容截断。
- 美股及部分海外市场若使用前一交易日收盘数据，必须在文案中标注日期，避免误写成 A 股当日同步行情。

## Verification
- `grep -c '{{' <报告.html>` 结果为 0。
- HTML 中六大板块完整：市场概览、技术形态、板块涨跌、关注板块、外围市场、总结与策略。
- PNG 长图无截断、无大段留白、footer 可见。
- 至少抽查 3 个关键数字可回溯到原始数据。
- 文案中不出现个人电脑路径、本地用户名、应用安装目录、桌面目录等敏感环境信息。
